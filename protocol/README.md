# Protocol schema

`schema.sexp` is the single source of truth for stable numeric protocol IDs.
The schema is declarative input to the OCaml generator. Generated OCaml and
Swift constants and debug names plus the readable ID table are committed. CI
runs the generator in `--check` mode.

IDs are never reused. Removing a field reserves its old ID. Additive optional
fields increment the protocol minor version; incompatible encoding or semantic
changes increment the major version.

The S-expression is not a runtime serialization format.

Generate or verify the committed artifacts from the repository root:

```sh
dune exec protocol/generator/generate.exe --
dune exec protocol/generator/generate.exe -- --check
make protocol-fixtures-generate
make protocol-fixtures-check
```

The two fixture producers have explicit ownership. OCaml generates
`ocaml_*.hex` output frames for the Swift decoder; Swift generates
`swift_*.hex` input event batches for the OCaml decoder. The opposite language
validates typed contents and byte-for-byte re-encoding. CI runs both producers
in `--check` mode and fails on missing or stale fixtures.


## Protocol 8 shared UI configuration

Protocol 8 replaces the environment and optional text-style layouts. Producers,
consumers and fixtures must use the same major version; no compatibility path is
provided. Default values live in OCaml `Theme.Defaults.Values`; `make protocol-check`
verifies the native baseline generated by evaluating those declarations.

An environment is mode U8 (0 System, 1 Light, 2 Dark), optional ARGB32 tint,
optional string font family, control size U8 (0 Mini, 1 Small, 2 Regular, 3 Large,
4 Extra_large, 5 inherit), followed by a U16 byte length and a fixed-layout sparse
configuration. Optional values use a 0/1 presence byte. All numeric fields are
little endian. Configuration fields, in order:

1. Fourteen optional F64 metrics in the order declared by OCaml `Theme.Defaults.Values.metrics`:
   symbol size, column spacing, interactive minimum, content inset, action
   spacing, action horizontal/vertical insets, small/search/card/sheet corners,
   border width, shadow radius and shadow Y. Symbol size and interactive minimum
   are positive; other metrics are nonnegative. All must be finite.
2. Nine optional ARGB32 colors: Primary, Secondary, Page, Card, Inset, Search,
   Border, Shadow, Material_tint.
3. Eight text-role pairs, each optional positive F64 size and optional U8 weight
   (0 Normal, 1 Medium, 2 Semi_bold, 3 Bold). Roles are Body, Page_title,
   Sheet_title, Editor_title, Empty_title, Caption, Hint, Section_label.
4. Optional U8 foreground-role selector (0–8).

5. Three optional F64 values: shadow X (finite signed), shadow alpha and material
   alpha (both finite, in `[0, 1]`).
6. Optional symbol rendering U8 (0 Monochrome, 1 Hierarchical, 2 Multicolor), then
   optional default text role U8 (0–7).
7. Eight role pairs: optional foreground U8 (0–8), optional italic Boolean.
8. Seven Surface-role groups (Unstyled, Plain, Material_action_group, Content_card,
   Inset_section, Translucent_sheet, Search): optional material U8 (0 Solid, 1 Thin,
   2 Regular, 3 Ultra_thin), optional shape Boolean (false Rounded, true Capsule),
   optional background color role U8 (0–8), optional F64 opacity and optional F64
   tint alpha (both finite, in `[0, 1]`).

Empty configuration is 96 zero bytes. Extra bytes, invalid tags and invalid
numbers are rejected before committing a frame. This is a fixed typed layout,
not a string-keyed property registry. Each scope merges only present fields.

A present text style contains optional size, weight, line spacing and ARGB32 as
before, followed by U8 text role (0–7 explicit, 8 inherit), optional U8 foreground
role (0–8), and U8 italic (0 false, 1 true, 2 inherit). Rich-text span italic uses
the same three-value encoding. Symbol rendering is U8 (0–2 explicit, 3 inherit).
Explicit values equal to the baseline remain explicit and override the Theme.

The existing standard Surface native widget now uses version 3, documented in
[Native decorative surfaces](../docs/swiftui-surfaces.md).
